# Orbital Foundry

**Orbital Foundry** is a browser-based 3D rocket and spaceflight sandbox.

This repository hosts the playable GitHub Pages version.

## Play

[Play Orbital Foundry](https://9950x3d.github.io/spaceflight-play/)

## Features

* **3D rocket builder** — build rockets with attachment nodes, symmetry, staging, procedural parts, saved rockets, and blueprints.
* **Flight physics** — rigid-body physics, aerodynamics, re-entry heating, collision damage, aircraft, helicopters, and marine vehicles.
* **Orbital mechanics** — patched conics, SOI transitions, maneuver nodes, encounter prediction, transfers, and time warp.
* **Spaceflight systems** — SAS, RCS, docking, EVA, crew, science, communications, life support, and multiple vessels.
* **Flight Director** — automatic guidance for launch, orbit, transfers, flybys, deorbit, and landing.
* **Career and exploration** — career mode, contracts, tech tree, procedural planetary systems, custom worlds, and asteroids.
* **Vessel systems** — ISRU, robotics, onboard flight programs, power systems, and resource management.
* **Optional Gemini tools** — AI Rocket Designer and AI Mechanic using the in-game vehicle and part systems.
